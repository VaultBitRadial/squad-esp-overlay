Features

Everything you need, drawn cleanly on screen

Six focused modules built around Squad's real entity data — no clutter, no wasted frames.

🟦

Player Box ESP

2D bounding boxes around every visible infantry unit, drawn from world-to-screen projection with smooth edge clamping.

🚙

Vehicle ESP

Separate box style and label for logistics trucks, APCs, helicopters and armor, so you can tell a transport from a tank instantly.

📡

FOB & Radio Hubs

FOB radio markers with build radius hints, drawn as distinct boxes so spawn points and habs are never a surprise.

📏

Distance Readout

Live meters-to-target text anchored under each box, updated every frame — accurate ranging for SL marks and grenade calls.

🦴

Bone Snaplines

Head-to-toe bone lines on infantry skeletons, giving you clean posture and aim-direction feedback at any range.

🎨

Team & Role Colors

Automatic faction coloring with role-based tints for medics, SLs, anti-tank and pilots — readable at a single glance.

How it works

Running in under two minutes

No loader chains, no driver installation. Grab the build, start the overlay, launch Squad.

1

Download the release

Grab the latest squad-esp-overlay archive from the download page and extract it to any folder — no installer, no admin prompt.

2

Launch the overlay

Run squad-esp-overlay.exe. It attaches as an external D3D11 transparent window and waits for the Squad process to appear.

3

Join a match and tune

Open the in-overlay menu to toggle boxes, snaplines, distance and FOB markers. Settings save to a local config on exit.
